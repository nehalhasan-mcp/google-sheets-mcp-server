# Google Sheets MCP Server

A custom Model Context Protocol (MCP) server built with Node.js and JavaScript to connect Claude Desktop with Google Sheets.

## Features

- Search Google Drive files
- Read Google Sheets data
- Search customers by name
- Search customers by email
- Search customers by status
- Add new customer records
- Update customer status

## Technologies Used

- Node.js
- JavaScript
- Model Context Protocol (MCP)
- Google Drive API
- Google Sheets API
- OAuth 2.0

## Integration

Claude Desktop + Google Sheets

## Project Status

Successfully built and tested locally with Claude Desktop.

## Purpose

This project allows users to interact with customer records in Google Sheets through Claude Desktop using custom MCP tools.

## Security

OAuth credentials and access tokens are stored locally and are not included in this repository.
